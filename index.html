Häufige Fragen

Mein Fortschritt ist nach einer Neuinstallation weg.
Öffne das Spiel und warte ein paar Sekunden: Ist der Cloud-Spielstand an, erscheint „PROGRESS FOUND!“. Auf einem neuen iPhone muss der iCloud-Schlüsselbund aktiv sein. Alternativ: auf dem alten Handy unter Einstellungen → CLOUD SAVE einen Übertragungscode holen und auf dem neuen Handy eingeben.

Ich habe Diamanten gekauft, aber nichts bekommen.
Starte das Spiel neu. Apple liefert unvollständige Käufe beim nächsten Start erneut aus. Hilft das nicht, schreib uns.

Wie lösche ich meine Online-Daten?
Einstellungen → CLOUD SAVE → DELETE ONLINE DATA. Cloud-Spielstand und Ranglisten-Eintrag werden gelöscht.

Das Duell sagt „different game version“.
Beide Spieler brauchen die neueste Version aus dem App Store.

FAQ

My progress is gone after reinstalling.
Open the game and wait a few seconds: with cloud save on, “PROGRESS FOUND!” appears. On a new iPhone, iCloud Keychain must be on. Or get a transfer code on the old phone (Settings → CLOUD SAVE) and enter it on the new one.

I bought diamonds but didn't get them.
Restart the game – Apple re-delivers unfinished purchases on the next start. If that doesn't help, contact us.

How do I delete my online data?
Settings → CLOUD SAVE → DELETE ONLINE DATA removes your cloud save and leaderboard entry.

A duel says “different game version”.
Both players need the latest version from the App Store.
